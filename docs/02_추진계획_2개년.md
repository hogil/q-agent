# 추진계획 — 2개년 8분기

**반도체 품질 이상감지·판단 AI Agent Orchestration 구축** · 과제 지원서 붙임 1

수행 기간 2026-09-01 ~ 2028-08-31 (24개월) ※ 제안값

---

## 0. 계획의 원칙

각 분기는 **무엇을 만드나**와 **무엇으로 검증하나**가 짝이다. 통과 조건을 채우지 못하면 다음 분기로 넘어가지 않는다. 일정이 밀리는 대신 검증되지 않은 것이 현장에 나가지 않는다.

권한은 위험도 순으로 연다. 1차년 내내 조치는 전건 사람 승인이고, 자동 실행은 0건이다. 2차년 6Q에 가서야 되돌릴 수 있는 조치부터 자동화를 시작한다.

## 2. 1차년 (2026-09 ~ 2027-08) — 구축·검증

### 1Q · 1~3개월 — 뼈대와 도구

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| 환경·접근 준비 | 정보계 조회 전용 계정, 에이전트 전용 뷰 | 조회 계정으로 UPDATE 시도 → 권한 거부 확인 |
| 조사 코어 골격 | adapter → investigator ⇄ tools → judgment → action → answer | 골든셋 4건이 end-to-end로 도는가 |
| 도구 8종 연결 | SQL 5종 · vision 2종 · RAG 1종 (조회부터) | 도구별 단위테스트 — 주어진 행 → 기대 JSON |
| 그라운딩 검증기 5칙 | 스키마 · 근거 실재 · 사실 대조 · 신뢰도 규칙 · 공백 금지 | 날조·왜곡·과장 3종 차단 재현 |
| 조사규칙 문서 v1 | 수치이상 · overlay · defect · 계측 · 자동감지 5종 | 현업이 직접 읽고 고칠 수 있는가 |
| 골든셋 4건 → 30건 | 정답 원인 + 금지 조치 포함 | 회귀 러너 전건 실행 |
| 체크포인터·감사 로그 | PostgresSaver, 판정 이력 스키마 | 프로세스 재시작 후 중단 지점 복원 |

**분기 통과 조건** — 골든셋 30건이 end-to-end로 돌고, 검증기 3종 차단이 재현되며, 조회 계정 권한 통제가 확인될 것.

**리스크 대응** — R1(도구 호출 품질)을 여기서 최우선 검증한다. 안 되면 라우팅만 규칙 기반으로 폴백하는 대안을 이 분기 안에 결정한다.

### 2Q · 4~6개월 — 그림자 운영

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| 그림자 운영 개시 | 판단만 수행, 조치는 실행하지 않음 | **AI 판단 대 엔지니어 판단 일치율 기준선 실측** |
| Chat UI | 스트리밍, 진행 단계 표시, 근거 패널 | 파일럿 엔지니어 사용성 확인 |
| 조치 실행기 dry-run | 실제 반영 없이 SQL 로깅 | 변경 0건 확인 |
| 승인 게이트 (HITL) | L2는 승인 없으면 실행 거부 | 미승인 실행 시도 → 거부 |
| 등록 워크플로 | AI 초안 → 엔지니어 확정 → 적재 | 등록 건수 누적 시작 |
| 과거 Inform Note 적재 | 초기 검색 자산 구축 | 색인 건수, 검색 실패 사례 리뷰 |

**분기 통과 조건** — 일치율 기준선이 수치로 확보되고, 그 값이 이후 회귀 게이트의 기준선으로 고정될 것. 조치 실행 0건일 것.

**여기가 이 과제에서 가장 중요한 분기다.** 신뢰를 여기서 번다. 일치율이 낮게 나오면 그 숫자를 그대로 보고하고 조사규칙·도구를 보강한 뒤 다시 측정한다. 낮은 기준선을 숨기고 넘어가면 이후 모든 회귀 판단이 무의미해진다.

### 3Q · 7~9개월 — Chat 파일럿

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| 파일럿 확대 | 포토 1개 공정, 엔지니어 부조종사 | 실사용 로그 — 질문 건수, 반려율, 재사용률 |
| 검색 품질 개선 | 질의 재작성 · 리랭커 · 용어 사전 확장 | recall@10 직전값 대비 상승, MRR·precision@3 추가 |
| vision 모델 학습·연결 | wafer map 분류, 결함 이미지 분류 | 확신도 낮으면 미지로 반환하는지 확인 |
| 판단 고도화 | 5개 증거원 종합, 원인 후보 순위화 | 골든셋 일치율 재측정 (기준선 대비) |

**분기 통과 조건** — 파일럿 엔지니어가 실제로 쓰고 있고, 검색 지표가 기준선 대비 하락하지 않을 것.

**대응** — 쓰지 않으면 적용 범위를 줄여 다시 파일럿한다. "만들었는데 아무도 안 쓴다"가 이 종류 시스템의 가장 흔한 실패이므로 통과 조건에 사용 여부를 직접 넣었다.

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| Event-to-Question Adapter | 이벤트 정규화 · 중복 제거 · 그룹핑 · 우선순위 큐 | 알림 폭주 없이 접수되는가 |
| 무인 모드 운영 | 24/7 자동 접수, 조치는 여전히 승인 대기 | **2주 연속 운영, 이벤트 처리 누락 0건** |
| 알림·교대 브리핑 | 메신저·메일 발행, 직전 교대 요약 자동 생성 | 수신자 유용성 평가 (유용/불필요 버튼) |

**분기 통과 조건** — 무인 2주 연속 운영에서 이벤트 처리 누락 0건, 자동 실행 조치 0건.

**1차년 종료 상태** — 포토 1개 공정에서 Chat과 무인 접수가 모두 돌고, 골든셋 회귀 게이트가 작동하며, 조치는 전건 사람 승인이다.

## 3. 2차년 (2027-09 ~ 2028-08) — 확산·자동화

### 5Q · 13~15개월 — etch 확산

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| etch 조사규칙·시스템지도 | 공정별 규칙 문서 추가 (코어 변경 없음) | **코어 diff = 0 확인** |
| etch 골든셋 구축 | 과거 사고 사례, 정답·금지조치 포함 | 회귀 러너에 신규 공정 추가 |
| etch 기준정보 연결 | 해당 공정 뷰·설비 마스터 | 도구별 단위테스트 |
| 확산 절차 문서화 v1 | 새 공정을 붙일 때 무엇을 하는가 | 다른 사람이 문서만 보고 따라할 수 있는가 |

**분기 통과 조건** — etch 골든셋 회귀 통과 + **코어 변경 0**. 이 두 가지가 동시에 성립해야 "확산 비용이 낮다"는 이 과제의 핵심 주장이 실증된다.

**R8 대응** — 확산이 코어 수정을 요구하면 확산 비용 가정이 무너진다. 그래서 코어 변경 0을 통과 조건으로 명시했다. 만약 변경이 필요하면 그 부분을 조사규칙 문서로 밀어내는 리팩터링을 이 분기 안에 수행한다.

---

### 6Q · 16~18개월 — CMP 확산 + 자동화 개시

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| CMP 조사규칙·골든셋 | 5Q와 동일 절차 반복 | CMP 회귀 통과, 코어 변경 0 |
| 자동조치 화이트리스트 | 되돌릴 수 있는 저위험 조치만 (재계측 오더 · 알림 · SPC 제외 등) | 시나리오별 승인율·오탐율 실측 근거 |
| L3 승격 심의 프로세스 | 시나리오 단위 개별 심의 기준 문서화 | 거버넌스 승인 |
| 3개 공정 동시 운영 | 포토 · etch · CMP | 3개 공정 회귀 동시 통과 |

**분기 통과 조건** — CMP 회귀 통과 + 자동조치 시나리오별 정확도 실측 근거 확보. 근거 없이 자동화하지 않는다.

**자동화 대상에서 제외되는 것** — 설비 제어, Lot Hold, 레시피 변경은 2차년에도 계속 사람 승인 대상이다.

---

### 7Q · 19~21개월 — 자동 실행 감사

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| 감사 로그 대시보드 | 누가·언제·무엇을 승인·조치했나 | 전건 추적 가능 |
| 자동 실행 전건 리뷰 | 자동으로 나간 조치를 사후 검토 | **오판율 측정·공개** |
| L3 승격 심의 운영 | 실측 근거를 놓고 시나리오별 심의 | 승격/보류 결정 기록 |
| 되돌리기 경로 검증 | 모든 자동 조치의 원복 절차 | 원복 리허설 |

**분기 통과 조건** — 자동 실행 로그 전건 감사 완료, 오판율이 수치로 보고될 것.

### 8Q · 22~24개월 — 선순환 정착과 확산 표준안

| 작업 | 만드는 것 | 확인 방법 |
|---|---|---|
| 등록·재학습 루틴화 | 사고 종결 → 초안 → 확정 → 적재 → 월 4회 재학습 | 등록 건수·재학습 주기 지표 |
| **확산 표준안** | 조사 코어 + 공정별 조사규칙 템플릿 + 골든셋 구축 절차 + 도입 체크리스트 | 다른 조직이 받아 적용할 수 있는 형태인가 |
| 3개 공정 동시 회귀 | 전 공정 골든셋 일괄 실행 | 전 공정 통과 |
| 2차년 결산·효과 실측 | 건당 처리 시간, 정답률, 산정치 대비 차이 | 최종 성과 보고 |

**분기 통과 조건** — 3개 공정 동시 회귀 통과 + 확산 표준안 산출.

**2차년 종료 상태** — 3개 공정이 24/7로 돌고, 되돌릴 수 있는 조치는 자동으로 나가며, 다른 조직이 가져다 쓸 수 있는 확산 표준안이 나와 있다.

## 6. 역할 분담 (RACI)

R 실행 · A 최종책임 · C 협의 · I 공유

| 활동 | 현업 (품질·공정) | 개발·모델 | 인프라·IT | 거버넌스 | 비고 |
|---|---|---|---|---|---|
| 조사규칙·시스템지도 작성 | **A/R** | C | I | I | 노하우의 주인은 현업 |
