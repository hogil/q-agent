## Application 명 / 정의

- **Application 명(후보)**: 품질 이상감지·판단 AI Agent (Q-Agent)
- **정의(1문장형)**: 제조 품질 데이터(Trend·Map·Image)와 사내 지식을 AI Agent 가 상시 감시·자율
  분석하여, 근거가 인용된 불량 판단과 조치안(Release/Hold)을 제시하고 엔지니어 피드백으로
  지속 정확해지는 LLM 기반 품질 판단 자동화 시스템.
- **정의(2문장형)**: 제조 품질 데이터(Trend·Map·Image)와 사내 지식(GPM·작업 Note)을 AI Agent 가
  24시간 감시하고, 이상 감지 시 필요한 시스템을 스스로 조회·분석하여 근거가 인용된 판단과
  조치안(Release/Hold)을 제시하는 품질 판단 자동화 시스템. 엔지니어의 검증·피드백이 학습으로
  반영되어 사용할수록 판단이 정확해짐.

## 역할/목적

품질 이상 1건의 판단에는 Trend 조회, Map·Image 확인, GPM 기준 대조, 과거 이력 검색 등 여러
시스템을 오가는 수작업 분석이 필요하며, 판단 품질이 담당자 경험에 좌우됨. 본 시스템은 이 분석
과정을 AI Agent 가 대행함 — 계측 Trend 를 24시간 감시해 이상을 조기 포착하고, 판단에 필요한
시스템을 스스로 조회·분석하여 근거가 인용된 판단과 조치안(Release/Hold)을 제시하며, 엔지니어는
대화(Chat)로 언제든 분석을 지시·검증함. **판단 소요 시간 단축(1인당 일 4시간 → 2시간)**,
야간·휴일 감시 공백 제거, 판정 일관성 확보를 달성함.

## 주요 기능

- 계측 Trend 24시간 자동 감시 — 변화 시점·변화량을 특정한 조기 경보
- 이상 발생 시 판단 정보 자동 수집: GPM 기준정보 조회, Wafer Map·Defect Image 판독,
  유사 과거 사례 검색(문서+이미지), 변경점 이력 대조
- 진성 불량 판단 및 Release/Hold 조치안 생성 — 판단 근거 원문 인용
- 대화형 분석(Chat): 자연어 질의에 실데이터 기반 답변
- 판정·조치 전 과정 자동 기록 — 감사·재발 분석 대응

## 시스템 특성

- 판단 LLM, 이미지 판독 모델, 불량 분류 모델, 시계열 이상탐지 모델, 검색 모델을 각각 사내
  데이터로 개별 학습하여 운영하는 **자체 모델 스택**
- LLM 이 SQL·이미지·시계열·검색 도구를 사안에 따라 **자율 선택·호출**하고 결과를 종합하는
  오케스트레이션 구조
- 사내 용어 사전 기반 **하이브리드 검색**(키워드+의미+이미지 유사도)으로 informnote·과거 사례 정확 검색
- Agent 의 시스템 접근은 **조회 전용**으로 제한, 조치는 엔지니어 승인 후 실행하는
  **Human-in-the-loop** 통제 구조

## 신규 구축 필요성

첫째, **감시 공백** — 이상은 야간·휴일을 가리지 않으나 수작업 분석은 근무 시간에 묶여 조기 대응
기회를 놓침. 둘째, **판정 노하우의 유실** — 베테랑의 판단 기준이 개인 경험에 머물러 인력 이동 시
조직에서 사라짐. 본 시스템은 판정 이력과 피드백을 학습 데이터로 축적해 조직 자산화함.
셋째, **기존 수단의 한계** — 사내 공용 LLM API·공용 RAG 는 문서 질의응답 전용으로, DB 조회·이미지
판독·Trend 분석을 결합한 도구 호출형 분석과 사내 용어·판정 논리의 도메인 학습이 불가하여 자체 구축 필요.

## 비즈니스 프로세스

1. (상시) Trend·Map·Image 수집 → 시계열 모델이 변화점 검출 시 Agent 자동 기동 /
   (수시) 엔지니어 Chat 질의로도 동일 분석 기동
2. Agent 가 GPM 기준·변경점 이력 조회, 이미지 판독, 유사 사례 검색을 자율 수행·종합
3. 진성 여부 판단 → Release/Hold 조치안을 근거와 함께 제시 → 엔지니어 승인/수정
4. 처리 결과·피드백이 학습 데이터로 자동 축적 → 정기 재학습·검증 절차를 거쳐 반영 —
   사용할수록 정확해지는 순환

## Application 기능/역할 (4분류)

- **상시 감시·조기 경보** — 시계열 모델+변화점 검출로 "언제부터, 얼마나"를 수치로 특정.
  완만한 shift·미세 변동 24시간 포착
- **도구 호출 종합 분석** — 판단 LLM 이 필요한 정보를 스스로 결정해 수집(GPM·변경점 조회,
  Map·Image 판독, 유사 사례 검색, 도면 판독) 후 원인 가설 수립·검증
- **근거 기반 판단·조치** — 진성 판단 + Release/Hold 조치안 + 근거 원문 인용 + 전 과정 자동 기록.
  조치 실행은 엔지니어 승인 통제
- **전 모델 자체 학습 체계** — 판단 LLM·이미지·검색 모델을 각각 사내 데이터로 개별 학습.
  피드백(채택/수정/기각) 자동 축적 → 정기 반영, 검증 통과 버전만 배포
