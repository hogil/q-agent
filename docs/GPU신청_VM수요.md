## 과제 상세

- **제목**: 품질 이상감지·판단 AI Agent(Q-Agent) 구축 — H100 GPU 클러스터 기반 서빙·학습 인프라
- **목적**: Trend·Map·Image 이상의 감지-분석-조치 자동화로 판단 지연·오판 수율 손실 저감,
  24시간 감시 공백 제거, 판정 노하우 자산화
- **내용**: ①감지(시계열·변화점 상시 감시, Map·Image 실시간 판별) ②분석(Agent 도구 자율 호출
  5~15회: DB·이미지 판독·유사사례·OCR) ③조치(근거 인용 Release/Hold 권고, HITL 승인, 버전 이력화)
  ④대화(Chat 실데이터 답변) ⑤학습(월 4회, LLM·이미지·검색 개별 학습) ⑥인프라(H100 20장 + BIG VM 5대 + NAS/OBJ)
- **대상**: 제조기술센터 품질·공정 엔지니어 약 1,000명. FAB·EDS 전 공정, DRAM·NAND 전 제품군
- **타겟 제품 기여(DRAM·NAND)**: ①진성 불량 조기 Hold → 불량 유출·고객 클레임 방지
  ②가성 불량 신속 Release → 불필요 Hold·라인 정지 저감 ③판정 4h→2h → Lot 대기 감소·TAT 개선
  ④판정 근거 자산화 → 신제품 램프업 판정 기준 조기 안정화.
  수율 보호·TAT 단축 = 제품 원가·납기 경쟁력 직결
