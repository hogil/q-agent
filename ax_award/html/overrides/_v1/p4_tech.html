3. 이미지 유사도 — 사내 이미지로 표현을 학습시킨다 (contrastive)
무엇을 같은 것으로 볼지를 가르친다
공개 가중치 그대로는 웨이퍼 결함을 구분하지 못한다. FAB 내 SEM, FAB out EDS, 전기 test Failbit Map을 모아 같은 사고번호·같은 불량 유형을 당기고 다른 유형을 밀어내는 대조 학습으로 인코더를 먼저 만든다.
당긴다 (positive)
같은 사고번호 · 같은 유형·같은 공정 · 같은 wafer 다른 배율
밀어낸다 (negative)
다른 유형 · 어려운 짝: 같은 공정인데 원인이 다른 것
증강에 금지 조항이 있다 — Map 계열은 회전·좌우반전 금지. notch 기준 방향 자체가 원인 정보라서, 돌리면 edge 편중과 방향성 결함이 같은 것이 돼 버린다. SEM은 밝기·대비·크롭만.
계획이 아니라 이미 돌려본 것이다 — 선행 프로토타입에서 ConvNeXt V2(FCMAE 사전학습) + 128차원 projection head로 갤러리 215장을 매칭했다. 군집 품질 AMI 0.956 · ARI 0.860 · 노이즈 0.52% (43 class × 30 = 900 wafer).
한 사고에 이미지가 여러 장일 때 — 세 방식을 규칙으로 가른다
장별 검색
+ 투표		장마다 따로 top-k → 사고번호 다수결. 기본값. 장수가 적으면 흔들린다
평균
임베딩		여러 장을 한 벡터로 평균. 같은 wafer 다배율에만. 모달이 섞이면 뭉개진다
Composite
Map		lot 내 wafer failbit을 한 장으로 겹쳐 조회. lot 단위 Map 전용. 개별 wafer 특이 신호는 사라진다
모달이 같고 같은 wafer면 평균, lot 단위 Map이면 composite, 모달이 섞이면 장별 투표 — LLM이 고르는 게 아니라 코드가 규칙으로 고른다.

② 선호 학습 (DPO)반려 사유

③ 검증기 보상 (GRPO)경로
데이터 한 사건에 답을 여러 개 생성 → 검증기 5칙 통과·인용 실재·도구 호출 수로 채점해 상대 비교. 사람 라벨이 더 없어도 는다.

후

셋이 고치는 곳이 다르다 — 지시 학습은 형식을, 선호 학습은 반려 사유를, 검증기 보상은 경로를 고친다. 검색 쪽은 같은 이력으로 임베딩·리랭커를 따로 파인튜닝해 recall@10을 올린다. 배포는 골든셋 회귀를 통과했을 때만 — 판정 정답률·recall@10·처리 시간·반려율 중 하나라도 떨어지면 막는다.
